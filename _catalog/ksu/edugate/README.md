## شكل `offering.json`

قائمة مقررات، كل مقرر:

```json
{
  "code": "CSC 227", "ar_code": "عال 227",
  "ar": "نظم التشغيل", "en": "Operating Systems", "h": 3,
  "college": "علوم الحاسب والمعلومات", "dept": "علوم الحاسب",
  "term": "الفصل الأول 1448/1449",
  "plans": [{"college": "...", "dept": "...", "major": "CSCN-علوم الحاسب"}],
  "sections": [{
    "no": "44176", "type": "محاضرة", "instructor": "...",
    "days": [2, 4], "time": "08:00-08:50 | 08:00-09:50", "room": "0160 31 1 A 013",
    "gender": "ذكر", "status": "مفتوحة", "campus": "الرياض- طلاب",
    "meetings": [{"days": [4], "time": "08:00-08:50", "room": "..."}],
    "exam": {"day": "2", "time": "01:00 م - 04:00 م", "date": "1448-07-12"}
  }]
}
```

- `days`: أرقام الأيام كما في الموقع (1 = الأحد … 5 = الخميس). `time` بصيغة 24 ساعة.
- `meetings` تظهر فقط لو للشعبة أكثر من موعد. `exam` لو له موعد اختبار نهائي.
- `plans`: كل التخصصات اللي ظهر المقرر في جدولها (الشجرة مرتبة بخطط التخصصات، لا بالقسم المالك للمقرر).
- **`college` و`dept` مستنتجة:** القسم اللي خططه فيها أكبر عدد من مقررات نفس الرمز. صحيحة لأغلب الرموز،
  لكن راجعوها قبل الاعتماد عليها (مثلاً مقررات المتطلبات العامة).

## اللي ما قدرت أوصل له

- **الفصول السابقة:** صفحة الزوار تعرض الفصل الحالي فقط، وما فيها اختيار فصل.
- **الدرجات غير البكالوريوس** (دبلوم، ماجستير، دكتوراه…): متاحة في الموقع لكن ما أخذتها. تشغيلها: `--degrees 5` مثلاً.
- **6 مقرات ما فيها تخصصات بكالوريوس:** الدراسات التطبيقية طالبات، كلية المجتمع بالملز، السنة المشتركة انتقالي،
  خارج مقر الجامعة، مركز تدريب شرق الرياض (طلاب وطالبات).
- **18 مقرر بدون رمز إنجليزي (و23 بدون اسم إنجليزي):** الواجهة الإنجليزية نفسها ترجّع لها الرمز العربي (أغلبها `ترخ`).
- **«البحث المتقدم»** (حسب الكلية/القسم مباشرة) عليه كابتشا، فما استخدمته.
- مقرر ما له أي شعبة مطروحة هذا الفصل ما يظهر أصلاً.

## إعادة التشغيل كل فصل

```
rm -rf .state        # checkpoint الفصل السابق
node scrape.js       # القوائم (≈30 دقيقة) ثم التفاصيل (≈6 ساعات) ثم البناء
```

Node 18+ بدون مكتبات. طلب واحد كل 1.1 ثانية، بدون توازي. لو انقطع: نفس الأمر يكمل من `.state/`.
لو طلع حظر أو كابتشا السكربت يوقف بكود خروج 2. `--phase build` يعيد بناء `offering.json` بدون أي طلبات.
