# أغلفة كتب المدرج (عيّنة المواد المشتركة)

أغلفة كتب منهجية من [دار جامعة الملك سعود للنشر](https://ksupress.ksu.edu.sa/ar/textbooks)، مصغّرة إلى 480 بكسل عرضاً (JPEG).
`covers.json` يربط كل مادة بكتابها وملف الغلاف وبصمته (sha256) ورابط صفحة الكتاب.

في القاعدة: الصورة في `public.media` بمفتاح بصمتها، ولكل مادة مساهمة `info` مثبّتة باسم حساب الموقع في `mudarraj.posts`
بيانها `{"book", "bookImg": ".../api/media/<sha256>"}`، نفس شكل أغلفة المسلخ.
